## 功能特性

✅ **自动播放视频** - 在官方播放器中真实播放，进度正常上报  
✅ **AI 智能答题** - 弹题自动作答：优先 AI 挑答案，答错自动换选项重试，直到视频继续  
✅ **连续学习** - 播完一节自动点击官方"下一节"按钮推进，直到整门课程完成  
✅ **手动控制** - 支持暂停、继续、停止操作  
✅ **AI 接口配置** - 兼容 OpenAI 格式（中转站 / 智谱 / 方舟 / DeepSeek），支持拉取模型列表、测试连接、保存配置  
✅ **Cloudflare 穿透** - 被 Cloudflare 拦截的接口自动经程序内置浏览器通道发出  
✅ **日志落盘** - 运行日志实时显示并写入 `learning.log`  
✅ **安全授权** - 需用户手动登录，不保存密码、Cookie 或令牌  
✅ **深色界面** - 深色主题 + 翡翠绿主题色

## 使用方法

### 方式一：解压即用（推荐，无需 Python）

从 [Releases](https://github.com/gitub-creater/xuexitong-auto-learner/releases) 下载
`学习通自动学习助手-解压即用.zip`，解压后双击 `学习通自动学习助手.exe`。

### 方式二：源码运行

```bash
pip install -r requirements.txt
playwright install chromium
python main.py
```

### 操作流程

1. **启动浏览器并登录**：点击按钮，在弹出的浏览器中手动完成学习通登录
2. **获取课程列表**：登录后点击，自动读取你的所有课程
3. **开始学习**：选择课程后点击，自动播放视频、处理弹题、连续跳转下一节
4. **控制进程**：随时暂停 / 继续 / 停止

### AI 答题设置

点击"AI 答题设置"：填接口地址（Base URL 填到 `/v1` 为止）、API Key，
可"拉取模型列表"选择模型、"测试连接"验证连通，保存到本目录 `config.json`。
未启用 AI 时使用本地策略（自动选选项让视频继续）。

## 技术架构

## 常见问题

**Q: 双击 exe 无反应？**
A: 确认解压后 `_internal` 文件夹与 exe 在同一目录。

**Q: 测试连接提示 Cloudflare / 403？**
A: 程序会自动经内置无头浏览器转发请求，首次约需 3-5 秒，请耐心等待。

**Q: 拉取模型列表报 403？**
A: 部分中转站不开放模型列表接口，直接手动输入模型名即可，不影响使用。

**Q: 学习进度不动？**
A: 保持浏览器登录状态；详细过程见 `learning.log`。
