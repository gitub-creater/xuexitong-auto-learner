# 学习通自动学习助手 - 发布版本

## v2.0 (2026-09-03)

### 🎉 重大更新

**下载地址**：[学习通自动学习助手_v2.0_绿色版.zip](./学习通自动学习助手_v2.0_绿色版.zip)

**文件大小**：约 49MB

**系统要求**：Windows 10 及以上

### ✨ 新功能
- ✅ 完整的AI答题支持（选择题、填空题、简答题）
- ✅ 智能答题策略：未启用AI时使用本地策略，答错自动重试
- ✅ 支持多种AI服务商（豆包、DeepSeek、通义千问等）
- ✅ Cloudflare防护绕过（自动使用浏览器通道）
- ✅ 翡翠绿深色主题界面

### 🐛 Bug修复
1. **未启用AI时不会误调用AI接口** - 严格的前置检查，确保只在配置正确时才使用AI
2. **题目识别失败时自动跳过** - 避免不完整的题目导致程序卡住
3. **优化视频播放流畅度** - 降低题目检查频率（每5秒一次），避免频繁扫描影响播放

### 📦 使用方法

#### 快速开始
1. 下载并解压 `学习通自动学习助手_v2.0_绿色版.zip`
2. 双击 `学习通自动学习助手.exe` 启动程序
3. 点击"启动浏览器并登录"
4. 在浏览器中完成学习通登录
5. 点击"获取课程列表"
6. 选择课程，点击"开始学习"

#### AI答题配置（可选）
默认使用本地策略答题。如需启用AI智能答题：
1. 点击"AI答题设置"
2. 选择服务商或填写自定义接口
3. 填写API Key和模型名称
4. 点击"测试连接"验证配置
5. 勾选"启用AI答题"并保存

详细说明请查看压缩包内的 `AI答题功能说明.md`
